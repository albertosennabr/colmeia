# Colmeia

App da comunidade Colmeia (Casa de Rainhas): autonomia e independência feminina através da sabedoria das abelhas.

- Front-end: React + Vite, publicado no GitHub Pages a cada push na `main`.
- Dados, login e arquivos: Supabase (projeto `colmeia`, região São Paulo).

```bash
npm install
npm run dev
```

Abre em http://localhost:3000.
